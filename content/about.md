Who can edit what: lab members can edit the projects they have commits in (the site reads each person's commits across the lab's repositories once a day), an admin can add or remove a person on any project, and Maintainers and Admins can edit every project. The rule in full is in [the maintainer protocols](https://github.com/desert-mango/hippocampus-docs/blob/main/docs/maintainer-protocols.md#2b-who-can-edit-which-project-everyone).
